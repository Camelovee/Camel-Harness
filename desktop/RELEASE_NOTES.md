Camel Harness 桌面预览版，内置 Python 后端，无需另装 Python、Node.js 或 uv。

- 新增运行账本：每次运行结束后记录终态、停止原因、模型、用量、改动文件、审批决定与子任务；右栏可在当前与历史运行之间切换。
- 运行账本展示工具与审批时间线、文件 diff，并可复制 Markdown 结案报告；复制时把用户主目录替换为 `~`。
- 界面精简：输入框图标胶囊与实心发送按钮、欢迎卡片、会话状态点；移除常驻快捷键说明、会话计数和重复的运行配置。
- 保留工作区、流式对话、工具审批、子任务、停止与恢复、暖白 / 中性夜色主题、三栏拖动和窄窗口模态详情。
- 会话日志新增 `run` 摘要事件；降级到旧版本可能无法读取新会话，建议升级前备份 `~/.camel/sessions`。
- 配置和会话保存在用户的 `.camel` 目录，更新应用保留数据。

**当前未完成正式签名**：macOS 仅使用 ad-hoc 本地签名，未公证；Windows 没有证书签名。系统可能拦截，请核验来源及 `SHA256SUMS.txt`。Git、项目语言环境和可选 MCP 程序仍需自行安装。本版不提供自动更新。

使用说明见仓库 `desktop/README.md`。
