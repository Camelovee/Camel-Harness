Camel Harness 桌面预览版，内置 Python 后端，无需另装 Python、Node.js 或 uv。

- 仅提供桌面产品入口，React 界面与 Electron 统一构建；不再提供独立浏览器入口。
- 提供 macOS Apple Silicon、macOS Intel、Windows x64 安装包。
- 支持工作区、会话、流式对话、工具审批、子任务、停止与恢复。
- 提供暖白 / 中性夜色主题、轻量面板动效与“减少动态效果”支持。
- 左中右三栏支持拖动分隔线、键盘微调和双击复位，窄窗口的执行详情作为模态面板打开。
- 工作区分组可展开和收起，保留当前会话、草稿与运行中输出。
- 紧凑输入框与聊天记录等宽，多行输入自动增高；设置头部与分类固定，切换分类不再上下跳动。
- 执行概览显示真实用量、文件与工具活动，支持工具和子任务详情；首次配置引导及快捷键可直接使用。
- 配置和会话保存在用户的 `.camel` 目录，更新应用保留数据。

**当前未完成正式签名**：macOS 仅使用 ad-hoc 本地签名，未公证；Windows 没有证书签名。系统可能拦截，请核验来源及 `SHA256SUMS.txt`。Git、项目语言环境和可选 MCP 程序仍需自行安装。首版不提供自动更新。

维护者发布前应确认三个平台构建和实际安装检查均通过。使用说明见仓库 `desktop/README.md`。
