# 前端路书

本页记录 Electron、React 界面、桌面打包与分发的已实现能力、待验证事项和按需扩展。运行时与入口层见 [Harness Runtime 路书](路书-Harness.md)；分支与发布约定见 [AGENTS.md](../AGENTS.md)，产品范围之外的能力见 [Harness Runtime 路书](路书-Harness.md#当前交付范围之外)。

## 已完成

- [x] 简洁分栏：减弱大面积按钮、改为贯通式平面布局，左右分隔线支持拖动、键盘及点击微调，缩窗保留宽度偏好
- [x] 视图稳定：侧栏与输入采用平面反馈，消息和输入等宽对齐；设置头部及分类固定，仅内容滚动，消除分类切换时的重新居中跳动
- [x] 紧凑输入：移除顶部常驻提示，默认单行低高度，多行自动增高并滚动，清空后恢复；保留输入法和读屏语义
- [x] 工作区折叠：点击分组可反复展开或收起，保留当前会话、草稿和运行中输出
- [x] 沙漠三栏工作台：全局顶栏、工作区导航、对话与运行账本，明暗主题配对、可中断面板动效、原生模态键盘操作和真实活动投影
- [x] 运行账本：每次 Run 提交审计摘要，右栏可切换当前与历史运行，查看状态、用量、审批、文件 diff 并复制结案报告
- [x] 控件与层级统一：输入框图标胶囊、实心发送按钮、欢迎卡片、会话状态点与按需说明，移除常驻快捷键提示和重复的运行配置
- [x] 桌面工程目录整理：共享桥接契约、统一设置 Hook 命名，后端产物与打包中间文件集中到 `desktop/build/`
- [x] 产品收敛为桌面端：React、主进程、测试与构建合并到 `desktop/`，移除浏览器启动、跨源开发与 Python 目录选择
- [x] Electron 桌面启动、动态本机端口和临时凭据、原生目录、退出确认与清理、失败后人工重启
- [x] 明暗主题、可收起侧栏、工具详情、首次配置引导、快捷键与工作区切换期间的发送保护
- [x] 桌面界面工作区/会话管理、多会话状态隔离、SSE 消息与工具投影、内联审批、取消和恢复
- [x] 子任务详情侧栏：在父会话内打开子任务的完整过程与审批
- [x] 前端分层检查与桌面构建 CI
- [x] PyInstaller 后端打包、DMG/NSIS 配置、三平台 CI 与草稿预发布流程；安装结果需独立验证
- [x] Apple Silicon Mac 本机 DMG 挂载、临时安装和双厂商离线流程验收；未使用真实密钥或外部模型
