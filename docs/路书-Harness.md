# Harness Runtime 路书

本页记录 `camel_harness` 运行时与 `camel_backend` 入口层的已实现能力、待验证事项和按需扩展。桌面界面与分发包见 [前端路书](路书-前端.md)。分支、提交与发布约定见 [AGENTS.md](../AGENTS.md)。

## 已完成

- [x] 双根包与单向依赖：`camel_backend → camel_harness.agent → camel_harness.llm`
- [x] 单会话、单活动 Run；运行任务与事件观察分离，支持 steering、取消和从完整消息边界恢复
- [x] Anthropic/OpenAI 官方 SDK 适配；按 Run 路由模型，统一消息、工具调用、思考增量与用量事件
- [x] 思考强度按 Run 选择：API `low/high/max`，桌面界面显示低/中/高
- [x] 四个核心工具、参数校验、审批、原子文件替换和大结果归档；归档失败不重试已有副作用
- [x] 入口统一参数校验，精简重复防御和单次包装；约束新增低概率防御需先取得同意
- [x] stdio MCP 连接、工具发现与注册、单任务连接生命周期和取消清理
- [x] Skills 内置/项目/用户发现及索引、正文、支持文件三层按需加载
- [x] 按 Hermes 方式改造记忆：MEMORY.md/USER.md 双文件、字符上限、单 memory 工具、每 Turn 完整注入、写入自动允许（PLAN 除外）与旧 JSON 迁移脚本
- [x] 子 Agent 隔离会话、工具白名单、父 Run 模型跟随、父任务取消时关闭子任务
- [x] 分离子 Agent 创建与运行：创建函数绑定共享依赖并注入 Runner，保留权限与资源所有权边界
- [x] 父会话承载子任务事件与审批；子任务终态审计、历史读取和父会话分支隔离
- [x] Context 模块集中维护默认提示与 explore/plan/general 角色提示，复用静态工作规则并隔离父子上下文
- [x] 每模型窗口、输出预算与显式思考模式；主请求／摘要统一安全余量，截断工具有限连续恢复及终态诊断
- [x] 历史压力压缩、完整工具区间保留及首事件前超限的每 Run 一次强制压缩重发
- [x] 分离压缩决策与执行：ContextManager 负责开关、最少消息、压力阈值与容量保护；CompactionEngine 只选择安全切点、生成摘要并校验压缩结果
- [x] 收紧 Agent 编排：抽出 TurnRunner 与 SessionCommitter，Agent 只保留公开生命周期、Run 循环、取消/steering 与唯一终态
- [x] JSONL 历史树与 Run 摘要、父子目录、模型与用量审计、受控读取当前分支登记的结果引用
- [x] 用户级 `config.json` 多模型配置；密钥不返回界面，模型更新在下一次 Run 生效
- [x] Windows 文件锁、重解析点、Shell 进程树与目录选择适配；专项 CI 已配置
- [x] 行为回归、Import Linter 依赖契约与锁定依赖的 CI
- [x] 架构总览与上下文管理、工具安全、会话、上下文压缩、记忆五篇机制说明

## 下一步

- [ ] 设计运行信息注入：明确工作区、平台、权限及运行预算等信息的来源与刷新时机
- [ ] 根据实际工具能力匹配提示，避免指导模型使用未提供的能力；先明确能力声明与角色限制的关系
- [ ] 记录 Windows 专项 CI 的原生运行结果，确认文件/记忆竞争、进程树和 MCP 清理；不能用其他平台的模拟结果代替
- [ ] 补充超长文件与真实进程异常退出后重启恢复的联动回归；已有流中断、取消和历史重放测试继续保留
- [ ] 增加脱敏运行诊断摘要，记录工具/审批耗时、压缩、重试和错误阶段，避免写入凭据与私人正文

## 按实际需求扩展

- [ ] MCP 重连：先明确连接失败后的工具可见性与在途调用副作用，避免自动重放
- [ ] 只读工具并行或 Hooks：当前工具按顺序执行，新增机制需有明确使用场景和取消规则
- [ ] 受限执行环境与提示注入防护：执行不可信代码前设计进程/文件/网络隔离，不能依靠 Shell 正则实现

## 当前交付范围之外

插件市场、多用户、后台 Run 调度、跨进程 Run 接管、自动记忆提取及向量检索不属于当前交付。运行账本同样不包含跨会话的全局运行索引、结案报告写入工作区文件或完整事件回放；这些能力需要新的需求与方案，不作为已实现成果。

架构边界见 [项目架构](项目架构.md)，回归覆盖见 [测试说明](../tests/README.md)。本机简历和面试材料存放在被 Git 忽略的 `docs/学习/`，不作为公开文档链接入口。
