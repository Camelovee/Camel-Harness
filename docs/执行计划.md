## 第二轮可靠性修正（2026-10-09，已完成）

先按用户要求提交上一轮基线：`37419d6 refactor(harness): 收敛运行职责并完善独立压缩配置`。下列修改逐步验证，暂不追加 Git 提交。

1. LLM 失败契约：StreamFailed 增加 retryable；Adapter 只发规范失败事件，Client 集中执行首事件前的瞬时失败重试，永久错误、输出后失败与耗尽重试只交付一次。SDK 内置重试关闭，避免叠加。
2. Session 提交取消：已经开始的磁盘提交等待确定结果后再传播取消，期间保留会话锁；绑定历史分支的游标也在提交后完成更新。
3. Shell 输出与进程：临时文件采集避免全输出驻留内存，统一结果存储层分块归档完整输出并生成预览引用；生产工厂注入存储能力，父/子 Agent 复用所属会话定位；超时/取消清理独立进程组。不配置存储的独立工具实例只提供有界预览，不伪称完整引用。
4. 上下文容量：最小消息数与关闭自动压缩均不能跳过安全预算检查；无可压缩完整区间时明确失败，不把超限输入继续发送给模型。
5. 动态上下文：每个 Turn 从基础系统提示重新组装资源，steering 更新检索任务，避免旧任务 Memory 或重复累积提示。
6. 工具错误边界：缺省权限采用保守服务，不再跳过权限；参数、审批与工具执行错误作为 ToolResult，取消继续传播；执行后的结果归档失败作为基础设施故障终止 Run，避免误导模型重复副作用工具。
7. 资源生命周期：runtime 负责 MCP/LLM 构造失败清理和整体关闭；子 Agent 借用 LLM 不关闭共享资源。Agent 关闭任务由自身持有，等待者取消不破坏清理，失败可重试；OpenAI 流退出时释放流资源。
8. 终态分类：新增 session_failed/context_failed/resource_failed/tool_failed/internal_error，模型故障保持 provider_failed；仍只有 agent_end 一种终态事件，JSONL 格式不变。

验证：Pytest 237 项、前端 15 项、离线协议评测 11/11；Ruff/格式、Mypy、Import Linter 4 项契约、WebUI build 与差异检查通过。没有真实模型请求，未修改用户会话或全局配置。临时文件采集不提供磁盘配额，Shell 进程组清理基于当前 POSIX 平台，不新增沙箱或后台任务系统。
