# 路书

本页按当前源码区分已实现能力、待验证事项和按需扩展。产品入口为本地 WebUI，核心运行时可被 Python 代码复用。CLI 和独立项目评测已移除；相关历史变更保留在 [变更记录](../CHANGELOG.md)。

## 已完成

- [x] 双根包与单向依赖：`camel_backend → camel_harness.agent → camel_harness.llm`
- [x] 单会话、单活动 Run；运行任务与事件观察分离，支持 steering、取消和从完整消息边界恢复
- [x] Anthropic/OpenAI 官方 SDK 适配；按 Run 路由模型，统一消息、工具调用、思考增量与用量事件
- [x] 思考强度按 Run 选择：API `low/high/max`，WebUI 显示低/中/高
- [x] 四个核心工具、参数校验、审批、原子文件替换和大结果归档；归档失败不重试已有副作用
- [x] stdio MCP 连接、工具发现与注册、单任务连接生命周期和取消清理
- [x] Skills 内置/项目/用户发现及索引、正文、支持文件三层按需加载
- [x] 双层长期记忆：关键词检索、预算内完整正文注入、审批维护、版本冲突和根目录保护
- [x] 子 Agent 隔离会话、工具白名单、父 Run 模型跟随、父任务取消时关闭子任务
- [x] Context 模块集中维护默认提示与 explore/plan/general 角色提示，复用静态工作规则并隔离父子上下文
- [x] 每模型窗口、输出预算与显式思考模式；主请求／摘要统一安全余量，截断工具有限连续恢复及终态诊断
- [x] 历史压力压缩、完整工具区间保留及首事件前超限的每 Run 一次强制压缩重发
- [x] 分离压缩决策与执行：ContextManager 负责开关、最少消息、压力阈值与容量保护；CompactionEngine 只选择安全切点、生成摘要并校验压缩结果
- [x] JSONL 历史树、父子目录、模型与用量审计、受控读取当前分支登记的结果引用
- [x] 用户级 `config.json` 多模型配置；密钥不返回浏览器，模型更新在下一次 Run 生效
- [x] WebUI 工作区/会话管理、多会话状态隔离、SSE 消息与工具投影、内联审批、取消和恢复
- [x] Windows 文件锁、重解析点、Shell 进程树与目录选择适配；专项 CI 已配置
- [x] 行为回归、Import Linter 依赖契约、前端分层检查和锁定依赖的 CI
- [x] 架构总览与上下文管理、工具安全、会话、上下文压缩、记忆五篇机制说明

## 按实际需求扩展

- [ ] Skills、MCP 配置界面：当前仅有预留面板，需先明确本地文件配置与界面修改的关系
- [ ] 分支导航与历史编辑：Session 已有分支 API，补充 HTTP 契约和 WebUI 交互后再开放
- [ ] MCP 重连：先明确连接失败后的工具可见性与在途调用副作用，避免自动重放
- [ ] 只读工具并行或 Hooks：当前工具按顺序执行，新增机制需有明确使用场景和取消规则
- [ ] 受限执行环境与提示注入防护：执行不可信代码前设计进程/文件/网络隔离，不能依靠 Shell 正则实现

## 当前交付范围之外

插件市场、多用户、后台 Run 调度、跨进程 Run 接管、自动记忆提取及向量检索不属于当前交付。扩展这些能力需要新的需求与方案，不作为已实现成果。

架构边界见 [项目架构](项目架构.md)，回归覆盖见 [测试说明](../tests/README.md)。本机简历和面试材料存放在被 Git 忽略的 `docs/学习/`，不作为公开文档链接入口。
