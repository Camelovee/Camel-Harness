# 路书

本页按当前源码区分已实现能力、待验证事项和按需扩展。产品入口为 Electron 桌面预览版，核心运行时可被 Python 代码复用。独立 WebUI、CLI 和独立项目评测已移除；相关历史变更保留在 [变更记录](../CHANGELOG.md)。

## 开发分支

长期开发使用 `harness-dev` 与 `desktop-dev`：前者基于 `main` 提取独立的 Harness 核心改动，后者汇总桌面工程并整合已验证的核心能力。跨端需求先完成核心回归，再合并到桌面分支验证接入；合并 `main` 或推送远程仍需用户明确命令。

## 按实际需求扩展
