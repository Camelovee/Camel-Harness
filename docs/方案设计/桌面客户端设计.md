# 桌面客户端设计

## 职责与数据

Electron 主进程拥有窗口和本机后端。React 渲染界面位于 `desktop/renderer/`，与主进程共用 npm 工程和构建流程，通过 HTTP/SSE 使用 Backend，Harness 不感知桌面框架。Python 保留两个根包，前端保持 `app → features → shared`。`desktop/bridge.d.ts` 统一桥接方法与菜单动作的类型，主进程、预加载、渲染界面及测试替身共用；只提供类型声明，避免沙箱预加载产生额外模块依赖。

开发模式启动 `uv run --no-sync python -m camel_backend.desktop`；生产模式启动 PyInstaller 目录中的独立程序。统一构建输出 `desktop/dist/renderer/`，打包后进入 `resources/renderer/`。Backend 接收该资源路径并静态托管，因此页面保留相对 `/api` 地址。安装目录仅保存程序，配置与 JSONL 仍在 `~/.camel`。

## 管道和本机接口

主进程生成临时凭据，通过 stdin 首行 JSON 传递 `token`、`frontend_dist`。Backend 绑定 `127.0.0.1:0`，完成初始化后通过 stdout 发送 `{"type":"ready","port":...}`。协议固定 UTF-8；诊断与协议分离，不回显原始启动输入。

主进程仅为自己窗口发往当前后端 `/api/` 的请求添加凭据，其他请求移除同名头。Backend 以常量时间比较凭据并检查 Host、Origin。凭据不进入 URL、页面桥接、配置或会话。业务 API 始终启用临时鉴权，关闭 API 文档和 CORS；移除独立浏览器入口及固定端口服务。目录选择完全由 Electron 原生对话框提供，后端不再维护平台选择器或相应 HTTP 路由。

- `GET /api/desktop/status`：查询活动主任务数量。
- `POST /api/desktop/exit`：在 RunService 启动锁内暂停新 Run 并查询数量。
- `DELETE /api/desktop/exit`：用户取消退出后恢复接收任务，既有 Run 继续。

确认退出时，主进程发送 `{"type":"shutdown"}` 并关闭管道。Backend 先关闭 Agent、工具和扩展，再结束 HTTP，避免 SSE 阻止退出。管道 EOF 同样触发清理。启动最多等 30 秒、退出最多等 15 秒；强制终止必须提示核验副作用。异常退出仅展示故障页，不自动重放任务。

## 窗口和交互

一个实例持有一个后端，不连接或接管另外启动的 Web 服务。重复打开聚焦已有窗口。默认 1280×840，最小 960×640；退出后不留托盘或后台 Run。

渲染进程开启 sandbox/contextIsolation，关闭 Node 集成。预加载层只提供原生目录选择、应用信息、菜单订阅及故障页重启；主进程验证窗口和主 frame 来源。外部 HTTP(S) 页面交给系统浏览器，其他外部协议不开放。

DesktopApp 组合导航、消息、输入和详情，沿用现有事件投影与状态隔离。主题经设置接口持久化，缺失时跟随系统。工作区目录选择及会话创建完成前禁止发送，避免误用旧目录。收起或缩窄详情不改变任务生命周期。

## 简洁主题与可调三栏工作台

视觉方向采用 macOS 工具类应用的克制层级：中性底色、留白和细分隔线，暖沙仅用于品牌与焦点。参考 [Apple 工具栏指南](https://developer.apple.com/design/human-interface-guidelines/toolbars) 减少常驻视觉负担。UI/UX 资料库的完整方案偏营销页，未持久化；采用验证过的极简样式、拖动替代操作及 React 订阅清理建议。

- 全局顶栏放置 Camel 矢量标志、当前工作区、两侧面板开关及设置。左侧管理工作区和会话，中央保留对话、内联审批与输入，右侧默认打开执行概览。
- 工作区分组的折叠独立于当前会话选择，重复点击可收起或展开，不重新选择第一条会话，不影响草稿及运行；切换或新建会话时重新展示对应分组，列表刷新和流式更新保持折叠状态。
- 1280×840 默认窗口下，左右栏分别为 236 / 280 CSS px。两条分隔线可拖动：左栏 200–360 px，右栏 240–440 px，中栏至少保留 420 px；有效上限随相邻面板与窗口宽度收紧。查看工具或子任务沿用右栏宽度。长消息和代码在各自阅读区滚动，输入区保持可达。
- 视口窄于 1180 px 时收起详情。手动打开使用原生 `dialog`，约束焦点并支持 Escape，关闭后聚焦详情开关。设置、重命名和删除确认同样使用原生模态语义。
- 新对话、欢迎建议、次要操作和输入区选项使用无底色的轻量控件，悬停提供柔和反馈；审批确认、发送与设置保存保留主要操作层级。导航、工具、审批和输入操作统一使用 Phosphor 线性矢量图标；Camel 标志复用应用已有 SVG 路径。使用系统中文与等宽字体，不引入外部字体请求。
- 左侧按钮使用 4 px 圆角和紧凑留白，输入框使用 6 px 圆角与次级平面底色，按压不再缩放；键盘焦点保留可见描边。聊天记录与输入框按主栏容器宽度共享 24 px 边距、760 px 阅读上限；窄窗口边距为 20 px，系统滚动条占位不改变对齐。
- 输入框移除顶部常驻标签，文本区默认单行、最小 32 px，内边距 8 / 12 px，工具栏间距 6 px；多行草稿自动增高至 180 px 后内部滚动，通过 `aria-label` 保留输入用途。
- 设置弹窗保持水平居中，顶部距视口 48 px，高度为 `min(680px, 视口高度 - 96px)`。标题、关闭按钮和左侧分类不随内容滚动；右侧独立滚动并预留滚动条空间，切换分类从顶部展示。加载、分类切换和展开编辑器不改变弹窗位置及高度。

| --- | --- | --- |
| 窗口底色 | `#f6f5f3` | `#202020` |
| 阅读面板 | `#ffffff` | `#242423` |

主题值集中在 `app/theme.css`，常用文字、强调文字与状态色均独立校验明暗对比度。工作台使用贯通的平面布局，分隔线负责区域边界；弹窗和输入区保留圆角，阴影仅用于浮层；状态同时提供文字与图形，不仅依赖颜色。

### 分栏交互

分隔线采用可聚焦的 `separator`，暴露关联面板与像素范围。拖动使用 Pointer Capture，松开、取消或失去捕获均结束调整，不遗留拖动态。左右键按 16 px 微调，Shift 按 32 px 微调，Home / End 到当前边界，Enter 收起并将焦点交回面板开关。双击恢复默认宽度；单击打开原生 Popover，提供缩小、增大、重置，满足单指针替代操作。

宽度在当前应用会话内保留；收起、切换详情和缩窗不覆盖原选择，重新展开或放大后恢复。没有新增用户配置字段。窄窗口继续使用模态详情，不提供无意义的右分隔线。

### 动效与状态一致性

- 面板切换立即提交 React 状态，记录切换前后的中栏几何位置，再以 transform 在 280 ms 内补间。快速重复操作取消旧动画并从当前画面继续，关闭组件时取消拥有的动画。
- 拖动直接更新布局，不叠加宽度或位置动画。面板进入 320 ms，消息和内容切换 220–320 ms，按钮反馈 120 ms。仅使用 opacity / transform 表达变化，不逐 Token 重播动画，不以动画结束事件驱动任务状态。
- `prefers-reduced-motion` 同时关闭 CSS 动效和位置补间。状态文字、输入和审批始终可操作，保留系统快捷键及可见焦点。
- 欢迎页建议仅填写草稿，不自动创建任务或调用模型。

### 执行概览的数据边界

右栏使用已有会话事件与模型配置，不新增业务 API。工具调用按 `call_id` 关联结果，保留未执行、成功、失败和未知语义；缺少结果只显示“暂无结果”，不凭运行状态猜测工具是否已执行。文件活动包含读取、写入与编辑，并明确操作和结果，不将所有涉及文件宣称为已修改。

输入占比来自最近请求的输入 Token / 当前模型窗口，说明不含输出预算。未知用量保持未知，本轮总量与最近输出分别展示。子任务继续按父会话委派位置显示，打开或收起详情不改变任务运行。

## 打包与验证

PyInstaller 收集解释器、官方 SDK 客户端与协议类型、MCP 客户端和内置 Skills；不收集无需求的 MCP CLI 或语音辅助依赖。后端目录包与中间文件分别生成到 `desktop/build/backend/`、`desktop/build/pyinstaller/`；electron-builder 将后端和 React 产物装入额外资源，生成 DMG 和 NSIS 包。渲染依赖已经打入 Vite 产物，安装包不再重复携带其 Node 模块目录；主进程仅使用 Electron、Node 内置模块和本地编译文件。Vite 自动生成 `licenses.md`，随渲染资源携带前端依赖许可。

三平台 CI 校验版本、原生架构、项目检查与实际打包应用。Electron 离线验收使用临时用户目录和本机 Anthropic/OpenAI 协议替身，覆盖 SDK 流、审批写入、主题、取消退出、确认退出及未完成消息不落盘，不使用真实密钥或外部模型。

预览版只做 macOS ad-hoc 本地签名，Windows 不做证书签名。版本标签只创建草稿预发布，由维护者决定公开时间。
