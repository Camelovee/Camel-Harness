## Camel Harness｜轻量 Python Coding Agent Runtime

**[实际开发时间]｜[个人项目 / 团队项目及真实角色]**

技术栈：Python 3.11+、asyncio、FastAPI、Anthropic/OpenAI SDK、MCP、JSONL、Pytest、React/TypeScript。

仓库：[Camelovee/Camel-Harness](https://github.com/Camelovee/Camel-Harness)

**项目简介**：面向本地代码任务实现可复用的 Agent Runtime，通过 CLI 和 WebUI 提供文件读取、修改、Shell 执行与任务委派；重点解决流式交互、工具副作用、上下文压力和会话恢复问题。

- **运行时编排**：实现单会话、单活动 Run 的异步 ReAct 执行，采用具体类型的生命周期事件和订阅机制解耦执行与展示；支持 Turn 安全点接收 steering 输入、主动取消与基于完整消息边界恢复。
- **协议与上下文**：使用官方 SDK 接入 Anthropic/OpenAI，将消息和流事件统一为厂商无关协议；分离动态上下文组装、压缩计划和 Session 提交，支持首事件前上下文超限时每 Run 最多一次强制压缩并重发。
- **工具与可靠性**：基于 Tool ABC/ToolProvider 扩展工具，统一参数校验、权限审批、超时与结果处理；截断参数禁止执行，文件修改采用同路径串行化与原子替换，归档故障终止 Run 而非自动重试已执行命令。
- **会话与扩展**：实现版本 1 的 JSONL 追加式历史树，保存完整消息、模型与用量，不逐 chunk 写入；支持分支上下文投影、父子会话目录、大结果引用受控读取、Skill 三层按需加载和 MCP 连接生命周期管理。
- **验证与交付**：配置静态检查、依赖契约与 CI，建立异步取消、工具链修复、真实本地 MCP 连接和上下文超限故障注入测试；截至 2026-10-10，仓库包含 335 项 Python 测试及 15 项前端测试，离线协议任务集为 11 项。

## 项目描述编辑指南（不放进正式简历）

### 项目篇幅不足时使用这三条

- 构建基于 asyncio 的 Python Coding Agent Runtime，统一 Anthropic/OpenAI 消息与流协议，使用生命周期事件支持 CLI/WebUI 实时交互、steering、取消和恢复。
- 实现上下文压缩与有界超限恢复、完整消息 JSONL 历史树、工具授权与副作用保护，避免保存残缺响应或自动重放历史工具；支持 MCP、Skill 按需加载和隔离子会话委派。
- 建立确定性协议测试、真实本地 MCP 集成测试及故障注入回归，通过静态类型与依赖契约保持模块边界；提供公开代码、运行文档和离线性能测量。

### 不应写成既有成果

- 不写“模型任务成功率 100%”：11/11 为脚本化协议评测，不是模型效果。
- 不写“当前真实任务成功率 60%”：旧版本 6/10 只是单次历史记录，不能代表当前版本。
- 不写“双厂商真实验证全部通过”：协议与 SDK 测试不等于真实服务烟测，现有评测记录尚未证明 OpenAI 真实烟测完成。
- 不写“生产级、高并发、Exactly-once、取消自动回滚、OS 沙箱”：项目没有这些保证。
- 不写“向量 RAG、记忆自进化、复杂多 Agent 调度”：当前 Memory 是轻量索引与关键词匹配，委派为隔离子 Agent，不是这些能力。
- 不写“性能提升 X% / token 降低 X%”：已有基准只有成本测量，没有受控优化对比。
