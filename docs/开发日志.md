# Camel Harness 开发日志

本日志按自然日记录当天完成的功能；架构说明和后续计划分别维护在[项目架构](项目架构.md)与[路书](路书.md)中。

## 2026-09-17

- 完成流式多 Turn ReAct Agent Runtime。
- 接入 Anthropic、OpenAI 两种官方 SDK Provider。
- 完成规范消息、工具调用、权限审批、MCP、Skill、Memory 和子 Agent 基础能力。
- 完成本地 JSONL 会话存储、上下文压缩、CLI、FastAPI、SSE 和 React WebUI。
- 完成 `camel_harness`、`camel_backend`、`camel_cli` 三个 Python 根包及其入口拆分。
- 增加架构边界测试和 Import Linter 约束。
- 验证：Python 测试、类型检查、代码检查、架构检查和 WebUI 构建通过。

## 2026-09-18

- 统一 LLM 请求、消息、工具定义和流式事件协议。
- 将规范消息收敛为 `UserMessage`、`AssistantMessage` 和 `ToolResultMessage` 判别联合。
- 将系统提示从会话消息中分离，并将 Provider 运行坐标移出 LLM 层。
- 增加 `LlmStopReason`，统一处理正常结束、长度截断和工具调用结束。
- 增加截断工具调用保护，长度截断时不执行不完整参数并补充错误工具结果。
- 完成 Provider 事件映射、消息持久化和 WebUI 事件投影迁移。
- 验证：Provider 契约测试、会话测试、类型检查、代码检查和前端构建通过。

## 2026-09-19

- 完成 `ContextManager`，统一项目规则、Skill、Memory 和上下文压缩入口。
- 完成追加式上下文投影与压缩摘要写回。
- 完成权限决策、参数校验、工具执行、超时和大结果归一化链路。
- 将 ReAct Turn、工具调用、审批事件和完整消息保存统一收入 `Agent`。
- 完成 `AgentEvent` 生命周期判别联合，覆盖 Run、Turn、Message、Tool 和 Approval。
- 将默认工具集收敛为文件读写、精确编辑和 Shell，并完成隔离子 Agent 委派。
- 验证：Agent 工具循环、上下文压缩、权限、消息持久化和架构测试通过。

## 2026-09-20

- 完成 `steer()` 运行中输入 FIFO，并在完整 Turn 安全点消费。
- 完成 `abort()` 主动取消、取消传播、Shell 子进程回收和 dangling tool result 修复。
- 完成 `resume()` 会话恢复，使用新 Run 继续执行且不自动重试历史副作用工具。
- 完成单 Agent 单活动 Run 约束、运行锁、结束竞态处理和 `wait_for_idle()`。
- 完成 Agent 自持有执行任务与 `subscribe()` 事件订阅机制。
- Backend 通过内存队列将订阅事件桥接为 SSE；CLI 和子 Agent 改为订阅事件消费。
- WebUI 增加运行中输入、继续执行和无文字暂停按钮。
- 验证：运行控制、恢复、SSE、CLI、WebUI 和架构测试通过。

## 2026-09-23

- WebUI 左下角增加设置入口与浅色设置弹窗，集中管理默认模型、思考模式和多个模型配置。
- 对话输入框增加模型下拉框；每个会话保存自己的模型选择，Run 和 Resume 使用实际选中的模型与 Provider。
- Backend 增加本机模型配置存储和设置接口；密钥只保存在权限为 `0600` 的本地文件中，接口不回传密钥。
- 切换模型或更新配置后重建空闲 Agent，活动 Run 拒绝切换，避免缓存实例继续使用旧配置。
- 验证：Ruff、Mypy、Pytest、Import Linter、WebUI 生产构建与 `git diff --check` 通过。
